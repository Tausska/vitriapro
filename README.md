# VITRIA PRO

Site vitrine de l'agence VITRIA PRO, spécialisée dans la création de sites web professionnels pour les TPE et PME françaises.

## Structure

- `index.html` : page d'accueil responsive, avec styles et interactions intégrés.
- `favicon.svg` : icône du site.

## Déploiement Cloudflare Pages

Ce dépôt est un site statique HTML. Pour le déployer sur Cloudflare Pages :

- Framework preset : **None**
- Build command : **laisser vide**
- Build output directory : **/** (racine du dépôt)

Connecter le dépôt GitHub `Tausska/vitriapro` à Cloudflare Pages, branche `main`.

## À finaliser avant publication commerciale

- Tester la réception des messages sur `contact@vitriapro.com` (le bouton de contact utilise déjà cette adresse).
- Rédiger et publier les mentions légales et la politique de confidentialité avec les informations exactes de l'entité qui exploite le site.
- Vérifier les obligations légales et fiscales applicables à l'activité.
- Vérifier les prestations réellement incluses et les conditions tarifaires avant de prendre des commandes.

Aucun témoignage client, résultat chiffré ou référence commerciale fictive n'est utilisé sur la page.
